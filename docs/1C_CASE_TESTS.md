# Сценарий тестов кейса «запчасть для техники»

Юнит- и интеграционные тесты живут в `tests/test_onec.py` (раздел request_part) и
`tests/test_gateway.py` (test_request_part_*). Живой прогон — через веб-чат
(http://127.0.0.1:8103/) или `/ask-text`.

## 1. Юнит-тесты генератора BSL (`test_build_part_request_code_shape`)

Проверки сгенерированного кода `onec._build_part_request_code(item, vehicle, qty)`:

- запросы внутри `execute_code` — строго однострочные;
- лемматизация + wildcard: «колёсные диски» → `%колёсный%диск%`; «кировец» → `%кировец%`;
- количество: `КолВо = 2;`
- склады кейса ищутся по наименованию (Склад инженера / текущего ОП / другого ОП);
- присутствуют создания всех четырёх документов и маркеры веток:
  `ЗаказНаРемонт`, `ПеремещениеТоваров`, `ЗаказНаПеремещение`, `ЗаказПоставщику`,
  `B1|`, `B2|`, `B3|`, `B4|`, `NO_VEHICLE|`, `NO_PART|`.

## 2. Юнит-тесты разбора результата (`request_part`, фейковый transport)

Вход — строка `onec_code` (формат execute_code), ожидание — контракт
`{found, vehicle, branch, docs, quantity, message, source}`:

| Тест | onec_code | Ожидание |
|---|---|---|
| branch1 | `B1\|000000008\|Трактор Кировец...\|Диск колесный задний\|DK-300\|1` | branch=B1, docs=[ремонт], в сообщении «складе инженера» и номер |
| branch2 | `B2\|РЕМ1\|ПЕР1\|...\|12345\|3\|проведено` | branch=B2, docs=[ремонт, перемещение], «текущего ОП» |
| branch3 | `B3\|РЕМ2\|ЗП1\|ПЕР2\|...` | branch=B3, docs=[ремонт, заказПеремещения, перемещение] |
| branch4 | `B4\|ТД00-000010\|...\|77777` | branch=B4, «заказ поставщику» |
| no_vehicle | `NO_VEHICLE\|Трактор Кировец...; Трактор МТЗ-82` | found=False, в сообщении список техники и «Уточните» |
| no_part | `NO_PART\|...` | found=False, «не найдена» |
| error | `ERROR\|...` | `RuntimeError` (наверх уйдёт в сообщение об ошибке) |

## 5. Известная особенность: порядок слов в поиске

ПОДОБНО-шаблон порядка-чувствителен: пользователь говорит «масляный фильтр»,
номенклатура — «Фильтр масляный». Поиск запчасти построен на независимом
совпадении ВСЕХ токенов (имя ИЛИ артикул), поэтому порядок слов не важен,
а цифровые токены (артикулы) матчатся по полю Артикул.
