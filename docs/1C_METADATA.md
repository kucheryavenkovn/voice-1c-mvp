# Метаданные информационной базы (1С:ERP)

Справочник по объектам базы, которые используются (или планируются) в голосовых
сценариях. Источник: `POST /api/get_metadata` 1C MCP Toolkit (фильтр + секция
`properties`), живые данные — `POST /api/execute_query`. Дата снятия: 2026-08-28.

> Обновление: `./q1c.ps1` + get_metadata (см. docs/1C_INTEGRATION.md).

---

## Документ.ЗаказПоставщику (реализовано: интент `order_part`)

Заказ поставщику — «закажи N штук X».

- **Шапка**: Организация, Партнер, Контрагент, Соглашение, Склад, Валюта,
  ХозяйственнаяОперация, Статус (Перечисление.СтатусыЗаказовПоставщикам),
  Менеджер, ЦенаВключаетНДС.
- **ТЧ `Товары`**: Номенклатура, Упаковка, **КоличествоУпаковок, Количество**,
  Цена, Сумма, СтавкаНДС, Склад (по строке), ЗаказПоставщику (в других доках).
- Номер: Строка(11), автонумерация, периодичность Год (номера вида `ТД00-000001`).
- Запись из кода: `РежимЗаписиДокумента.Запись` (без проведения); шапку копируем
  с последнего существующего заказа (см. `onec.create_order`).

## Документ.ЗаказНаРемонт

«Заказ на ремонт» — прямой аналог сценария из кейса duplexV2T (техника + работы
+ запчасти). **В базе есть живые документы.**

- **Шапка**: Организация, Подразделение, **ОбъектЭксплуатации**
  (Справочник.ОбъектыЭксплуатации — ремонтируемая техника), ОбщийВидРемонта,
  Приоритет, РемонтноеМероприятие, НаименованиеРабот, ДатаНачала/ДатаЗавершения
  (+фактические), **Статус** (Перечисление.СтатусыЗаказовНаРемонт:
  КВыполнению → Выполняется → Закрыт), Ответственный, Комментарий.
- **ТЧ `МатериалыИРаботы`**: Номенклатура, Упаковка, КоличествоУпаковок,
  Количество, **Склад**, ВариантОбеспечения (Перечисление.ВариантыОбеспечения),
  КодРемонта — запчасти/материалы на ремонт.
- Прочие ТЧ: `Ремонты` (узлы/виды ремонта), `РабочиеЦентры`, `УстраняемыеДефекты`
  (→Документ.РегистрацияДефекта), `Трудозатраты` (виды работ, бригады).
- Номер: Строка(9), непериодический (`000000007`). Проведение разрешено
  (движения: скорее всего регистр обеспечения/ремонтов).
- Живые примеры: «Автопогрузчик АМКОДОР 211 Инв. №456432» (статусы Выполняется /
  Закрыт), «Полуавтомат сварочный А-825М Инв. № 784041».

## Документ.ПриобретениеТоваровУслуг

Поступление товаров и услуг — «приход по заказу» (закрывает петлю заказа).

- **Шапка**: Партнер/Контрагент/Соглашение/Организация, **Склад** (основной),
  Валюта, **ЗаказПоставщику** (ссылка на заказ — поступление по заказу),
  НомерВходящегоДокумента, СуммаДокумента, НалогообложениеНДС.
- **ТЧ `Товары`** (39 колонок): Номенклатура, Упаковка, КоличествоУпаковок,
  Количество, Цена/Сумма/НДС, **Склад, ЗаказПоставщику** (по строке), ВидЗапасов,
  Серия. Прочие ТЧ: `ВидыЗапасов`, `Серии`, `РасшифровкаПлатежа`,
  `ЭтапыГрафикаОплаты`, `ШтрихкодыУпаковок`.
- Номер: Строка(11), периодичность Год (`ТД00-000002`).
- Живые примеры: партнёры «Альфа», «Веселый пекарь», «База "Электротовары"»;
  поступление ТД00-000001 ссылается на заказ ТД00-000001.

## Документ.ПеремещениеТоваров

Перемещение между складами — кандидат на сценарий «перенеси N X со склада А на склад Б».

- **Шапка**: Организация (+ОрганизацияПолучатель), **СкладОтправитель,
  СкладПолучатель** (склады ТОЛЬКО в шапке, не в строках!), Статус
  (ПеречислениеСтатусыПеремещенийТоваров: …Принято), ЗаказНаПеремещение,
  ХозяйственнаяОперация, Ответственный.
- **ТЧ `Товары`**: Номенклатура, Характеристика, Упаковка, КоличествоУпаковок,
  Количество, Серия. Прочие ТЧ: `ВидыЗапасов`, `Серии`, `ШтрихкодыУпаковок`.
- Номер: Строка(11), периодичность Год (`ПР00-000001`).
- Живые примеры: «Склад отдела снабжения (ЭЛ-1) → Склад отдела снабжения М1»,
  «Западный склад → Торговый зал», статус «Принято», проведены.

## Справочник.Склады

Иерархический (группы и элементы). Ключевое:

- `Наименование` (50), `ТипСклада` (Перечисление.ТипыСкладов: ОптовыйСклад /
  РозничныйМагазин), `Подразделение`, флаги адресного/ордерного хранения,
  `ЦеховаяКладовая` (признак цеховой кладовой).
- **42 склада**: Центральный склад, Западный склад, Склад бытовой техники,
  Склад металла, Склад электронных компонентов, Склад полуфабрикатов,
  Продуктовая база, Мебельный склад, Торговый зал (+ПСН/УСН), Магазины,
  цеховые кладовые (столярный, малярных работ, мехобработки, сборки ЭК…),
  таможни.

## Справочник.Номенклатура

Иерархический, 110 реквизитов. Ключевое для голоса:

- `Наименование` (100), `Артикул` (50), **`ЕдиницаИзмерения`**
  (→ Справочник.УпаковкиЕдиницыИзмерения — «единица хранения»; её же кладём
  в строку документа как `Упаковка`), `ЕдиницаДляОтчетов`.
- **`ВидНоменклатуры`** (Справочник.ВидыНоменклатуры — аналитика вида),
  `ТипНоменклатуры` (Перечисление.ТипыНоменклатуры: Товар / Работа / …),
  `ИспользованиеХарактеристик` (варианты), `СкладскаяГруппа`, `СтавкаНДС`.
- Живые виды: «Комплектующие и запчасти для бытовой техники», «Холодильники»,
  «Освещение», «Шины и автопокрышки», «Материалы основные», «Продукты».
- Живые позиции: Indezit 1330 (арт. 0167899), Рефрижиратор, Уплотнитель
  (вид «запчасти для бытовой техники»), Лампа LED ЭРА A60/A65, Покрышка
  автомобильная, Рем.комплект №1/№2.

## Справочник.ОбъектыЭксплуатации (связан с ЗаказНаРемонт)

«Техника/объекты в эксплуатации» — то, что ремонтируем:

- Группы («Автомобили полученные в аренду (лизинг)»…) и элементы:
  «Автопогрузчик АМКОДОР 211 Инв. №456432», «Полуавтомат сварочный А-825М
  Инв. № 784041», «Обрабатывающий центр ПЦ-80», «Nissan Almera», ноутбуки,
  стеллажи, здания. Идентификация в наименовании — инв. №, без госномеров.

## Общие закономерности (важно для кода)

1. **Пара количеств везде**: во всех товарных ТЧ (`ЗаказПоставщику.Товары`,
   `ПриобретениеТоваровУслуг.Товары`, `ПеремещениеТоваров.Товары`,
   `ЗаказНаРемонт.МатериалыИРаботы`) — `КоличествоУпаковок` (видимое в форме) +
   `Количество` (в единицах хранения) + `Упаковка`. Заполнять все три.
2. **Номера документов**: Строка(11) с префиксами (`ТД00-`, `МС00-`, `ПР00-`,
   `ДС00-`, `СБ00-`), периодичность Год — уникальность в пределах года.
3. **`objectRef` в execute_query**: колонка-ссылка возвращается структурой
   `{_objectRef, УникальныйИдентификатор, ТипОбъекта, Представление}` — наш
   парсер рассчитан на строки/числа, поэтому в запросах всегда разворачиваем
   ссылки через `.Наименование` (как в `_build_query`).
4. **Статусы — перечисления**: у заказа на ремонт/перемещения есть свой
   статусный ряд; произносить пользователю лучше Представление («К выполнению»).
