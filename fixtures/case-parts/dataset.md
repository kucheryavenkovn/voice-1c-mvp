## Поступления

- Документ: `Документ.ПриобретениеТоваровУслуг`, по одному на каждый склад
- Дата: **15.07.2026 10:00** (прошлым месяцем), режим записи — **Проведение**
- Шапка — копия последнего существующего поступления (партнёр/организация/соглашение/валюта)
- Строк на склад: инженер — 10, текущее ОП — 11, другое ОП — 10

## Скрипт ассистента (целевое поведение)

Инженер: *«нужен колёсный диск для Кировца»* →

1. Подбор техники: нечёткий поиск в `ОбъектыЭксплуатации` («Кировец» → К-744Р А123ВС04)
2. Проверка остатков по складам в приоритете: инженер → текущее ОП → другое ОП
3. Маршрут по наличию:
   - инженер → `ЗаказНаРемонт` (стоп)
   - текущее ОП → `ЗаказНаРемонт` + `ПеремещениеТоваров` (ОП → инженер)
   - другое ОП → `ЗаказНаРемонт` + `ЗаказНаПеремещение` + `ПеремещениеТоваров` (заполнение по заказу)
   - нигде → `ЗаказПоставщику`
